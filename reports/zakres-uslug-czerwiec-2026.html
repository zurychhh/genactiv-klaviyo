Test A/B: GEN-6 vs NOTOAGENCY (analiza i wnioski)
Analiza
  • Naprawa trackingu A/B — wykryto, ze 89% sesji nie mialo tagu wariantu. Przyczyna: Pandectes consent manager nie eksportuje window.gtag. Fix: polyfill gtag + direct dataLayer.push w obu motywach (GEN-6 ID 199333609804, NOTOAGENCY ID 190479794508)
  • Pelny raport A/B (docs/AB_TEST_RAPORT.md, 14.7 KB) — 28 195 wizyt, 661 zamowien, 14 dni. Wynik: NOTOAGENCY -20.9% CR (p=0.025, istotne statystycznie), -20.7% revenue/visitor, +21.1% abandoned checkout
  • Diagnoza przyczynowa — strata skoncentrowana na karcie produktu mobile: wariant kapsulki 120 szt. -47% CR, 60 szt. -63% CR. Przyczyna: zmiana wariantu wymusza pelny reload strony w NOTO. Dowod: proszek (bez wyboru wariantu) +9%
  • 9 priorytetow naprawczych (docs/REKOMENDACJE_KARTA_PRODUKTU_MENU.md, 23.3 KB) — spec dla GRAFIK + DEV: Section Rendering API (P1, +25-40% ATC), pill buttons (P2), sticky ATC (P3), above-the-fold PDP (P4), fix dead clicks (P5-P6), bottom nav bar (P7), homepage (P8), PageSpeed (P9)
  • Integracja Clarity UX — custom tags ab_theme_variant i theme_id wdrozone w obu motywach. Analiza: 553 dead clicks ATC/mies., 4 944 dead clicks na nazwach produktow, 34 rage clicks colostrum-120
  • Raport weryfikacyjny (reports/AB_TEST_WERYFIKACJA_2026-06-16.html) — walidacja danych Intelligems vs GA4 vs Clarity po naprawie trackingu
