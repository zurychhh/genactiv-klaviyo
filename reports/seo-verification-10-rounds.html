RUNDA 7 Agent: Image ID Format

Weryfikacja formatow ID obrazkow

Przeanalizowano updateProductImages.ts linia po linii:

BLOCKER GID mismatch potwierdrzony
  • Audit zwraca: gid://shopify/ProductImage/75127364321612
  • Narzedzie konstruuje: gid://shopify/MediaImage/75127364321612
  • Mutation productUpdateMedia oczekuje: MediaImage GID
  • Numeryczny ID z ProductImage =/= numeryczny ID z MediaImage
  • Walidacja (linia 77-81) dopasuje po numerze, ale mutation uzyje blednego GID

Wymagany fix: zmiana query z product.images na product.media, lub uzycie productUpdate mutation zamiast productUpdateMedia.
