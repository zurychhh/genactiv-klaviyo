| `75058399576396` | Present | Present |

**Impact:** When ALT text is set on a shared image via one product, it may or may not propagate to the other product depending on Shopify's internal data model. In Shopify, ProductImage records can be shared via file references. Setting ALT text on the same image ID from two different products should be idempotent (same image, same ALT), but the ALT texts should ideally be product-specific (different product name in ALT). If the image ID is truly shared (same DB record), then only one ALT text value will persist.

**RISK:** If ALT texts are written with product-specific names (e.g., "FIBERBIOM z ananasem dwupak" vs "FIBERBIOM z ananasem"), the second write will overwrite the first. The ALT text should either be generic for shared images or they should be treated as the same update (last writer wins).
