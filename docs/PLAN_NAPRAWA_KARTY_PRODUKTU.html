Kontekst i diagnoza

Kluczowy wniosek z testu A/B: Nowy motyw NOTOAGENCY wygrywa lub remisuje wszedzie poza karta produktu. Strata nie jest rozsiana — siedzi w jednym ekranie. Motyw Shopify wdraza sie w calosci (nie da sie mieszac), wiec naprawiamy karte wewnatrz NOTO, re-testujemy, i dopiero wdrazamy calosc.
Dotyczy: motywu NOTOAGENCY (Shopify theme ID: 190479794508). GEN-6 (stary motyw, ID: 162539340108) jest na produkcji i zostaje bez zmian — to nasz baseline/kontrola.

D1 · Section Rendering API — zero reload na zmianie wariantu

To jest jedyna przyczyna spadku -47/-63% na kapsulkach. Obecna karta przeladowuje cala strone przy zmianie 60/120/dwupak.

// Schemat: Uzytkownik klika wariant → JavaScript: preventDefault() → fetch(`/products/${handle}?variant=${variantId}&sections=${sectionId}`) → API zwraca JSON z renderowanym HTML sekcji → JS podmienia DOM: cena, zdjecia, dostepnosc, stan ATC → history.pushState() aktualizuje URL
WymaganieSzczegol
Zero page reloadSection Rendering API + fetch() + DOM swap
URL updatehistory.pushState() z parametrem ?variant=ID
Aktualizacja cenyPodmiana innerHTML z odpowiedzi sekcji
Aktualizacja galeriiZdjecia tagowane do wariantow; swap z odpowiedzi
Dostepnosc + ATCEnable/disable na podstawie dostepnosci wariantu
Fetch URL format/products/{handle} (nie /product/), parametr variant (nie variant_id)
Czas reakcji< 300ms od klikniecia
Transfer~2-5 KB (zamiast 200-500 KB przy reload)

Wzor: Shopify Dawn — snippets/product-variant-picker.liquid (web components <variant-radios>, <variant-selects>)

Test akceptacyjny: Otworz karte kapsulki 120 szt. na mobile (Chrome DevTools → Fast 3G). Kliknij „60 kapsulek” — strona NIE moze sie przeladowac. Cena, zdjecie, URL zmieniaja sie w < 500ms. Scroll position bez zmian. ATC aktywny i klikalny.

D2 · Fix dead clicks ATC

Clarity: 553 dead clicks na „Dodaj do koszyka”, 6,7% sesji mobile z JS errors, 34 rage clicks na karcie kapsulek 120.

  • Sprawdzic: event listener podpiety po DOM ready?
  • Pandectes consent blokuje skrypt?
  • Intelligems A/B konflikt z theme JS?
  • Race condition: przycisk przed handlerem?
  • Fallback: setTimeout 3s → prosty addEventListener na .product-form__submit
  • Test z wylaczonym Pandectes i Intelligems osobno
Test: 100 klikniec ATC na roznych produktach (kapsulki/proszek/krem/dwupak) = 0 dead clicks. Chrome Android, Safari iOS, Samsung Internet.
