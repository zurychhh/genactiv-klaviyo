13 zadan · 3 etapy
Glowna przyczyna straty: Na karcie NOTO klikniecie wariantu (60/120/dwupak) powoduje pelne przeladowanie strony. Na mobile LTE = 2-4s bialego ekranu. Uzytkownik traci kontekst i odpada. Dowod: proszek (bez wyboru wariantu) ma +9%, kapsulki -47/-63%.

Etap 1 — Krytyczny (przed re-testem)

DEVETAP 1
+25-40% ATC

D1 · Section Rendering API — zero reload na zmianie wariantu

To jest JEDYNA przyczyna spadku -47/-63%. Transfer: 2-5 KB vs 200-500 KB przy reload.

// Schemat dzialania: Uzytkownik klika wariant → JavaScript przechwytuje event (preventDefault) → fetch(`/products/${handle}?variant=${variantId}&sections=${sectionId}`) → API zwraca JSON z renderowanym HTML sekcji → JS podmienia elementy DOM: cena, zdjecia, dostepnosc, stan ATC → history.pushState() aktualizuje URL bez nawigacji

DEVETAP 1
553 fix

D2 · Fix dead clicks „Dodaj do koszyka”

Clarity: 553 dead clicks na ATC, 6,7% sesji mobile z JS errors, 34 rage clicks na /products/colostrum-genactiv-120-kapsulek.

  • Sprawdzic: event listener podpiety po DOM ready?
  • Pandectes consent blokuje skrypt?
  • Intelligems A/B konflikt z theme JS?
  • Race condition: przycisk renderowany przed handlerem?
  • Fallback: setTimeout 3000ms → prosty addEventListener na .product-form__submit
  • Przetestowac z wylaczonym Pandectes i Intelligems osobno
Test: 100 klikniec ATC na roznych produktach = 0 dead clicks. Chrome Android, Safari iOS, Samsung Internet.
DEVETAP 1

D3 · Implementacja pill buttons wg mockupu grafika

Liquid + CSS. Zachowac AJAX zmiane wariantu (D1). Animacja zmiany stanu 150-200ms transition. Elementy na kazdym buttonie: nazwa + cena + cena/kaps. Pre-selekcja najpopularniejszego.

DEVETAP 1

D4 · Sticky ATC bar — Intersection Observer

Observer na oryginalnym ATC button. Toggle class .visible na sticky bar. Sync z variant selector (zmiana wariantu = update ceny w sticky). Z-index pod modalami.

// Intersection Observer na oryginalnym ATC const atcButton = document.querySelector('.product-form__submit'); const stickyBar = document.querySelector('.sticky-atc-bar'); const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { stickyBar.classList.toggle('visible', !entry.isIntersecting); }); }, { threshold: 0 }); observer.observe(atcButton);
